# Lampiran Resume Matrix RPJMD dan Matrix Forum SABABUKA

## A. Konteks expose antara

Setelah expose pendahuluan, tim melanjutkan pekerjaan dengan Matrix RPJMD Kabupaten Kapuas sebagai sumber acuan pemetaan awal di SABABUKA. Resume ini menjadi bahan forum. Angka, OPD penanggung jawab, serta status organisasi belum menjadi keputusan final sebelum diverifikasi BAPPERIDA dan OPD pemilik.
