## Aturan pengelolaan berikutnya

1. Setiap observasi menyimpan nama sumber, URL, status verifikasi, dan waktu pengambilan.
2. Angka hasil perhitungan wajib menyimpan rumus dan angka pembentuk pada catatan.
3. Ketidakcocokan definisi tidak boleh diselesaikan dengan asumsi; indikator dikembalikan ke Bapperida/OPD untuk penguncian metadata.
4. Data demo tetap boleh dipakai untuk presentasi alur, tetapi harus tampil dengan label yang berbeda dari data resmi.
